# OCDP / 互补蒸馏：方案与当前实现的对照

**一句话**：三层结构（Teacher 提互补 → Student 预测互补 → 三级蒸馏）逻辑是通的，OCDP 头部的参数量与耗时几乎为零，初始恒等性也能保住；但文档描述的 Teacher 与仓库里的 Teacher 不是同一个对象，另有两处实测结果与文档给出的建议方向相反。

---

## 1. 方案复述（我理解到的）

| 层 | 角色 | 输入 | 输出 | 训练信号 |
|---|---|---|---|---|
| Teacher | **真的看见**另一轨 | (目标轨, 反轨) | `U_T` 互补表征、`G_T` 任务相关度 | 双轨监督 |
| Student **OCDP** | **看不见**另一轨 | 单轨 + OrbitID | `U_S`=动态卷积预测的互补、`G_S` 空间门 | 只受蒸馏 |
| Distillation | 三级层次 | — | — | `U_S→U_T`、`G_S→G_T`、`z_S→z_T`，单一 `λ_KD` |

核心对应句：Teacher 提取「另一视角贡献了什么」，Student 学「这份缺失的贡献应在**何时**、以**何种方式**出现」。层级指**知识层级**（内容 → 支持 → 决策），不是 P3/P4 尺度。

`correction` → `complement` 是纯命名变更，代码里对应 `r3/r4`；本文档统一写 `U_T`。

## 2. 与当前代码的逐项对照

对照对象：`models/landslide_cocd_v2.py`（294 行）、`scripts/23_train_ours_v2.py`。

| 方案组件 | 仓库现状 | 差距 |
|---|---|---|
| Teacher 是双轨模型 | `forward_pair(asc, desc)`，两轨各过一次共享 ConvNeXt-Tiny/FPN，**恰好 2 次编码** | 一致 |
| 反轨**如何**进入 | 加性修正 `p4d = p4t + r4`、`p3d = p3u + r3`；`r` 来自 `Correction(256)` 与 Ω 零参照 `Ω(a,c)=op(cat(a,c))−op(cat(a,0))` | 与「deformable cross-attention + complement decomposition」**不是同一个结构** |
| `U_T` | **存在**，就是 `r = (r3, r4)`，两尺度各一个 | 只是命名（代码叫 correction） |
| `G_T` 任务相关度 | **不存在**。教师没有任何 relevance / gate 输出，`Ft + G_T·U_T` 在代码里就是 `p3 + r3` | **缺口** |
| 现有的 gate | `gain × protect`，在**损失里**由 self/dual 的 BCE 现算（`selective_kl`） | 它不是教师输出，不能直接当 `G_T` 用 |
| Student 结构 | R0–R3 修正算子阶梯；R2/R3 继承 Ω + 零初始化 driver | 与 OCDP 完全不同 |
| OrbitID 建模 | 第 5 通道**常数平面** `full((1,128,128), 0. if asc else 1.)`（`scripts/21:43`） | 没有 orbit embedding |
| 动态卷积 / 空间门 | 不存在 | 缺口 |
| 「FPN 不算创新」 | FPN 一直是骨架，从未当卖点 | 一致 |
| 注意力/可变形算子 | **全仓自研模型里一个都没有**（只在 `third_party/` 的 DIS2 与 smp 里） | 缺口 |

**因此：「Teacher 定住，不再动它的主逻辑」与文档描述的 Teacher 不能同时成立。** 文档要求 Teacher 输出 `U_T` 和 `G_T` 两个量，而当前 Teacher 只有 `U_T`。这是必须先解决的分叉，见 §4 D1。

## 3. 实测（本机、现有代码、现有 checkpoint）

### 3.1 可变形算子在本机只在一条路上可训练

```
torchvision.deform_conv2d   cpu : 前向 OK，反向 OK
torchvision.deform_conv2d   mps : 前向 OK，反向 NotImplementedError
torch.nn.functional.grid_sample  cpu/mps : 前向与反向都 OK
```

`torchvision::_deform_conv2d_backward` 在 MPS 上未实现 ⇒ **直接用它训练会当场失败**。
文档里的 Deformable Cross-Attention 若要落地，必须用 `grid_sample` 手写（已按 MSDeformAttn 的标准写法做过前向+反向验证，MPS 上通过）。这是一个真实的工程约束，不是风格选择。

### 3.2 OCDP 头部的代价 ≈ 0

| | 参数量 | batch 16 单步 | 换算 |
|---|---:|---:|---:|
| R3 现有 | 28.2715 M | 712 ms | 2.75 min/epoch |
| R3 + 两尺度 OCDP(K=4) | 28.7289 M（**+457 K，+1.6%**） | 702 ms | 2.72 min/epoch（**0.986×**，噪声内） |

原因是两个落点分辨率低：128 输入下 P3 = 16×16、P4 = 8×8。K=1/4/8 的两尺度成本分别是 210 K / 457 K / 787 K。

### 3.3 初始恒等性保得住，但轨道分支第一步梯度精确为零

调制 MLP 与专家末层都零初始化时：

```
max|F_out - F_t| ＝ 0.000e+00          初始仍是未修正函数（现有「所有臂同一起点」的断言可保留）
同一输入、两条轨道的调制后特征差异 ＝ 0.000e+00   初始时 orbit 条件尚未起作用
调制 MLP 末层是否有梯度 ＝ False
专家末层是否有梯度     ＝ True
```

机制：初始 `gate × U ≡ 0`，于是 `out = F_t + 0`，`∂out/∂F_o` **精确为 0** ⇒ 调制分支在第 1 次更新收不到任何梯度，第 2 步起才有。这与仓库里既有的 Driver/Ω 完全同型（`Ω(a,0)=0` ⇒ 驱动未打开前继承算子的梯度恰为零）。不是缺陷，但属于必须断言并披露的性质。

### 3.4 ★ `U_T` 在合成 no-change 样本上是真实样本的 12 倍

冻结 v1 Teacher，eval，12 个 batch：

| 样本组 | 单轨样本数 | `|U_T|`(=r4) 均值 | max | 非零概率像素占比 | 分割损失 |
|---|---:|---:|---:|---:|---:|
| 真实 pre→post | 70 | **0.2169** | 3.34 | 50.05% | > 0 |
| 合成 pre/pre、post/post | 122 | **2.6665（12.3×）** | 13.21 | **0.00%** | **精确 0.0** |

两张表征在同一批样本上完全解耦：**决策输出精确为 0（既有的惰性事实），而互补量在那些样本上最大。**

解释（假设，可证伪）：当前 `U_T` 更像是「反轨特征的新奇度」而非「任务相关的互补」。no-change 对的目标轨与反轨是**不同轨道**的 pre 栅格，特征差异大 ⇒ `Ω` 输出大；而那里真正需要的互补≈没有。若成立，则文档对 `G_T` 的需求恰恰被这条实测支持——但也意味着**把 `U_S→U_T` 直接嫁接在当前 `U_T` 上，学生学到的是「在无变化对上凭空生成一个很大的互补」**。

### 3.5 `L_comp` 的量级与文档建议相反

取学生初始 `U_S = 0`，则 `L_comp` 的初始量级就是 `U_T` 到零的距离：

| 划分 | `L1(U_T,0)` | `MSE(U_T,0)` | 同期 seg | 占 seg（L1 / MSE） |
|---|---:|---:|---:|---:|
| **val（纯真实）** | 0.2062 | 0.0782 | 0.1230 | **167.6% / 63.6%** |
| train（含合成） | 1.8315 | 7.5575 | 0.0045 | — |

train 上 **66.2% 的样本（合成）贡献了 `L_comp` 量级的 95.4%**。

两条结论：

1. **`L_comp` 不在「通道太窄」的区间，而在相反的区间。** `L_Δ` 曾是 seg 的 0.42%（需要 `λ≈25–30` 才与 KD 同权），`L_comp` 在真实样本上直接是 seg 的 1.7 倍 ⇒ 若要它不压过分割目标，权重得**远小于 1**。两者差 ~14 倍。
2. **文档 §8「把 `gain×protect` 只留在最后一层」会把 95% 的 `L_comp` 梯度交给标签被强制置零的合成样本**，而且要求匹配的目标在那些样本上是「一个很大的互补」。这一条实测上不支持。

## 4. 动手前必须先定的三个口径

**D1 —— `G_T` 从哪来。** 三条路，性质完全不同：
- (a) 真冻 Teacher：`G_T` 只能用非学习量代理（如教师 self/dual 后验差、`gain` 的空间化版本）。它不是一个「学习出来的任务相关度」，论文里不能写成教师输出。
- (b) 按文档重做 Teacher（加可变形交叉注意力 + 显式 `G_T` 输出）：这是**改主逻辑**，Teacher 要重训，v1（`teacher.pt`）与 v2（`teacher_v2.pt`）两套软目标与 Ω 全部作废或另表；已跑的学生臂也要重跑。
- (c) 先不做 `G_T`：只做 `U_S→U_T`（`L_comp`）+ 决策层，`G_S` 作为 Student 内部结构存在但不单独蒸馏。

**D2 —— `gain×protect` 是否留在 `L_comp`/`L_gate` 上。** §3.4/§3.5 的实测支持**保留**（至少在真实对上的掩膜），与文档 §8 的建议相反。若坚持只放决策层，需要在结果里如实说明「特征级项的主体来自无变化对」。
另外，文档希望「只留一个 `λ_KD`」：三个项的天然量级差约 14 倍（`L_comp` 1.67×seg，`L_pred` 0.12×seg），单个 λ 实际等价于「`L_comp` 是目标、另两项是装饰」。要么先各自归一化，要么接受这个事实并写清。

**D3 —— `U_T` 与 `U_S` 的参考点不对称。** Teacher 的 `r3` 是在**未修正的 P3** 上算的（`Ω(a3, c)`，`a3 = p3t`），而 Student R3 的 `r3` 在**已被 P4 修正的 a3** 上算。逐尺度匹配 `U_S→U_T` 就是让学生去追一个在不同参考点上定义的量（传播距离 L2 = 66.3，不可忽略）。要么统一参考点，要么只在 P4 上匹配（P4 两侧一致）。

## 5. 建议的落地顺序

**第一段（不碰 Teacher，可立即做）**
1. Student 侧加 orbit 条件（调制 + 动态专家 + 空间门），两尺度，零初始化，配 `init parity` 与「第一步零梯度」两条断言。
2. 蒸馏先只做 **P4 上的 `L_comp`**：那里 `U_T`/`U_S` 参考点一致（D3 自动规避），且 `u_T4 = r4` 是现成的，不需要教师提供任何新输出。
3. 此时它已经是「R3 + 互补内容蒸馏」，比此前提出的 `R3 + L_Δ` 更有直接依据；`R3` 仍是精确对照（结构、KD、初始化全同，只差这一项）。
4. 先量 `L_comp` 的份额与权重，再定时长。

**第二段（要拍板才动）**
5. 决定 D1。若选 (b)，可变形交叉注意力与 Ω 是同一个位置的两种机制（都在 P3/P4 做加性注入），因此**「Ω vs 可变形注意力」本身就是一条受控比较**，和 R1/R2/R3 在「修正量怎么产生」这条轴上是并列的。这条比较有独立价值，无论 OCDP 最终成败。

**不建议现在做**：把 `U_S→U_T`、`G_S→G_T`、`z_S→z_T` 三项一次全上。三项的天然尺度差 14 倍，且 `G_T` 的定义还没定，同时上线会让任何结果都不可归因。

### 文档里我认为成立、且与项目一致的部分

- `correction` → `complement` 是纯重命名（代码里对应 `r3/r4`），成本低；
- 「不要再拿 multi-scale pyramid 当创新」——FPN 在本项目从未当过卖点；
- 「OrbitID 不再只是第五通道塞进去」——这条**说的正是现状的欠缺**（现状就是常数平面），不是错配；
- 「全程保持 CNN/FPN、不引 Transformer token」——与项目现状一致；
- 三级里"决策级"仍用 `gain×protect`——与现有 `selective_kl` 一致；
- `correction → complement` 的动机（教师"看见" vs 学生"预测"）在叙述上比"修正"更贴合 LUPI 设定。

## 8. 决策记录（2026-09-18 16:36，用户裁决）

### 8.1 已裁决

| # | 裁决 |
|---|---|
| 1 | **新老 Teacher 彻底区分。** 旧 Teacher 定名为 **Additive Cross-Orbit Teacher**（`target feature + Ω(target, counter)`），只作旧机制基线，继续服务 R0–R3 / Vanilla KD / DIS2-port / 旧 COCD 结果 |
| 2 | **不再把 `r3/r4` 称为 task-relevant complement。** 合成 no-change 上 `r` 反而巨大，说明它是 feature discrepancy / novelty |
| 3 | **删除人为构造的 `G_T` 监督层。** 新 Teacher 只留一个蒸馏对象 `C_T` |
| 4 | **feature-level 蒸馏也必须受 `gain×protect`（或等价 task-valid mask）控制** |
| 5 | **不同时上线三层 KD** |
| 6 | **Student 不上 K=4 expert router**，改为 orbit FiLM + 单个内容自适应 gated conv block |
| 7 | **新结构替代 R0–R3 时，旧结果降级为 previous-design ablation**，不再混进同一结构阶梯 |
| 8 | **`λ_KD` 前必须先归一化**（`L̄_i = L_i / EMA(L_i)`，或 train 初始统计固定一次） |

### 8.2 新设计里仍未定义、会卡住实现的点

| # | 未定义 | 为什么关键 |
|---|---|---|
| a | **`C_T` 如何进入解码器** | 若仍是 `F_t + C_T → z_dual`，则注入位置与 Ω **完全相同** ⇒ 新 Teacher 是「换一种算法算这一项」。受控比较因此是 **Ω vs (deformable + separator)，注入点不变**；这也决定新老 Teacher 能否直接比 |
| b | **`C_T` 的零参照** | 旧 Ω 有 `Ω(a,0) ≡ 0`，使「关掉反轨」良定义、且支持 counter-dropout 诊断。新 separator 若要保留该性质必须显式构造（减去 counter 为零的前向），否则「反轨的边际贡献」无定义 |
| c | **task anchoring 具体写成哪一项** | 「让 `z_dual` 优于 `z_self`」**不能直接写成约束**（无界 max-margin 型）。目前可监督的相关性只有 `gain×protect` 这个事后量——它本身就是 relevance 的度量，只是不是学出来的。需明确 anchoring 由「正常 `z_dual` 分割损失 + 对 `C_T` 的最小性/稀疏约束」实现，还是别的 |
| d | **`F̃_t` 是否进解码器** | 进 ⇒ orbit 条件被分割损失在**所有**样本上监督；只进 complement 分支 ⇒ orbit 条件只在 `w>0` 的 1/3 真实样本上被监督。这决定 orbit embedding 能否学到东西 |
| e | **归一化用 EMA 还是固定统计** | EMA 有两个已知风险：① 项目已踩过「某项长期趋零」（DIS2 `div` → 0.0000）与「整批为零时自动配平退化到钳位下界」；② EMA 让权重随**各臂自身**损失历史漂移 ⇒ **臂间可比性下降**。建议改用**train 初始统计固定一次**，跨臂同尺度且可复现 |
| f | **`L_Δ` / `R3D` 的处置** | 已实现、54 条断言通过、**从未训练**。丢弃 / 留作 legacy 臂 / 并入 `L_pred`？随之 `lam_delta` 也悬空 |
| g | **新 Student 需要自己的消融阶梯** | 旧 R0–R3（继承 Ω、递进驱动）在新结构里不存在 ⇒ 新方法「各部分各贡献多少」没有对应实验。最小阶梯建议：`N0` 单轨 → `N1` +orbit FiLM → `N2` +gated complement → `N3` +selective distillation |
| h | **零初始化的首步零梯度** | `h` 零初始化 ⇒ `C_S ≡ 0` ⇒ `∂out/∂F̃ = 0`，FiLM 与 gate 在第 1 次更新均无梯度（与已实测的 Driver/Ω 同型）。可接受，但需断言并披露 |

### 8.3 裁决对仓库状态的三个直接后果

1. **`teacher_v2.pt` 恰好是现成的对照组。** 它是 Ω 在统一协议（Adam 5e-5 / batch 16 / 20 ep）下的 20-epoch 结果（val `z34` AUPRC 0.6671、val 阈值 0.206）。若做新 Teacher，新老对比只需新 Teacher 一次训练，控制组已在盘上。
2. **待跑的 v2 sweep 在新计划里仍然需要。** `SO` 是下限；`VKD`/`DIS2`/`R3` 是「旧机制在统一协议下」的参照。建议照跑（约 5 h），新 Teacher 作为**后续独立加入**，不要混进同一次 sweep。
3. **命名要在新老并存期间保持一致含义。** 代码里 `Correction` / `correction_loss` / `L_corr` 保留原义；`complement` 只用于新 Teacher 的输出 `C_T`，避免同一个词指两个对象。

### 8.4 两处建议再收一下

- **「只蒸馏 `C_T` 一个对象」与后文不一致。** 新 Teacher 端确实只新增 `C_T`（删掉 `G_T`），但 §λ 那段写的是 `L_KD = L̄_comp + L̄_pred` —— 两项。`L_pred` 就是现有的 `selective_kl`（决策级），它是本项目**唯一被验证过有量级**的蒸馏项，不应被删。建议统一表述为：**新 Teacher 只新增一个知识对象 `C_T`；蒸馏共两项** `L_comp(C_S, C_T) + L_pred(z_S, z_T)`。
- **Student 收缩后，两侧结构不再镜像。** Teacher 是 deformable interaction + separator，Student 是 FiLM + gated conv。若「对应」是论文卖点，需要说清对应的是**知识对象**（`C_T`）而非**结构**。

## 9. 关键限定：以上异常有多少是 **v1 协议专属**（2026-09-18 20:0x 实测补充）

用户裁决建立在「合成样本上 `r` 巨大」这条观测上。该观测取自 **v1 冻结 Teacher（S0 暖启 + AdamW 1e-4 + 50ep）**。而新设计将在 **统一协议 v2（ImageNet 冷启 + Adam 5e-5 + 20ep）** 下训练，`teacher_v2.pt` 已经跑完 —— 因此必须逐条核对这些性质在 v2 下是否还成立。

同一批训练数据（10 batch），两个 Teacher：

| 量 | v1 Teacher（S0 暖启 50ep） | v2 Teacher（冷启 20ep） |
|---|---|---|
| 真实样本 `|U_T|`(=r4) 均值 | 0.2163 | 0.2313 |
| 合成样本 `|U_T|` 均值 | **2.6765（12.4×）** | **0.4613（2.0×）** |
| 真实样本 概率非零像素占比 | 50.57% | 100.00% |
| 合成样本 概率非零像素占比 | **0.00%（精确饱和）** | **100.00%（完全未饱和）** |
| 真实样本 `w` 均值 / w>0 像素占比 | 0.0716 / 11.93% | **0.4586 / 61.36%** |
| 合成样本 `w` 均值 / w>0 像素占比 | **0.000000 / 0.00%** | **0.000188 / 0.02%**（max 0.9997） |

### 9.1 三条必须改口的记录

1. **「2/3 合成样本惰性、损失精确为 0」是 v1 协议专属。** v2 下 `teacher_v2` 在合成样本上概率非零像素占 **100%**，BCE 损失非零 ⇒ **合成样本会产生真实梯度**。所以「44.5% / 3.9% 零梯度滑行步」「2/3 样本自 S0 起完全惰性」在 v2 都不适用，v2 是 3,699 个样本全都在训。v1 的饱和源于 S0 的 50 epoch 暖启 + 50 epoch 训练把 no-change 对的 logit 压到 `sigmoid` 逐位为 0。
2. **「合成互补量是真实的 12 倍」是 v1 协议专属。** v2 下是 **2.0×**（0.4613 vs 0.2313）。方向仍一致，但量级大幅减弱。**裁决②（不再把 `r` 叫 task-relevant complement）的正当性来自结构——`r` 的定义里没有任何任务相关性——这条不受协议影响；但那个 12× 的数字必须标 v1 引用。**
3. **`w` 在 v2 下不再是稀疏选择器。** 真实样本上 `w` 均值 **0.4586**、w>0 像素 **61.36%**（v1：0.0716 / 11.93%，约 6.4× 与 5×）。原因是 v2 Teacher 更弱、其 self 路径拟合更差，从而 dual 在更多像素上「更好」。**推论：「Ours 的选择性 KD」与「Vanilla KD」在 v2 下的实质差别，主要来自排除那 2/3 合成样本，而不是像素级选择。** 论文里不能把 v2 的 `gain×protect` 写成「只在少数关键像素上蒸馏」。

### 9.2 裁决⑤④仍然成立，但机制要写对

- 用户设计的 `L_comp = Agg[w·D(C_S, C_T)]`、`L_pred = Agg[w·KL(z_S, z_dual)]`，靠 `w` 切断合成样本 —— **在 v2 下确实成立**（合成样本 w>0 仅 0.02%）。但**成立的理由与 v1 不同**：v1 是「`e0 = et = 0` 使 gain 与 protect 双双退化」，v2 是「dual 在那些样本上并不优于 self，故 `protect`≈0」。
- **风险**：v2 下 `w` 在真实样本上活跃到 61%，说明该机制**并不保守**——只要 dual 略优就会开启。合成样本上 `w` 恰好≈0 是**经验上的接近**，不是结构性保证（实测合成样本 `w` 的最大值到过 **0.9997**，即个别像素已接近全权重）。
- **建议（一行改动）**：在两项蒸馏上再乘一个样本级 `1_real`（loader 已经逐样本提供 `real`）。这样「合成 no-change 对绝不参与互补蒸馏」从经验巧合变成**结构性保证**，也与裁决 (b) 保留 `Ω(a,0)≡0` 定义性性质的思路一致。

### 9.3 归一化常数必须在 v2 + 新 Teacher 下重测

`w` 的均值在 v1/v2 间差 **6.4×**（0.0716 → 0.4586），且 `s_comp` 还取决于新 Teacher 的 `C_T` 尺度。**裁决 (e) 的「固定 train-only 归一化常数」不能用 v1 的任何数字，必须在 v2 协议、新 Teacher 下、开跑前用固定的真实样本子集统计一次并冻结。**

## 10. 最终定稿（2026-09-18 20:24 用户裁决）

方法只回答两个问题：**Teacher 如何提取另一轨提供的互补信息；Student 如何在缺另一轨时预测这份互补。**

### 10.1 Teacher — Deformable Complement Extraction

```
H_tc  = DCA(F_t, F_c)                        # 轻量 deformable cross-attention
C_T   = Φ(F_t, H_tc) − Φ(F_t, DCA(F_t, 0))   # 互补表示
F_T   = F_t + C_T
z_self = D(F_t)      z_dual = D(F_T)
L_T   = L_seg(z_self, y) + L_seg(z_dual, y)  # 各 0.5
```

无 gate、无 task anchoring loss、无稀疏项、无 P3/P4 递进、无 gain/protect、无额外正则。

- **零参照由定义本身保证**：`C_T(F_c=0) ≡ 0` 是代数恒等式（两项字面相同）。**因此不需要**对 DCA 附加「无 bias / 无 query 残差 / 零输入输出零」这类约束 —— 本文档 §8.2(b) 与 §9.2 里那类要求**作废**。
- 任务相关性来自 `C_T` 的唯一用途：`F_t + C_T → 滑坡预测`，梯度即 GT。不再单独制造 relevance 目标。
- DCA 的作用只有一个：target 不强制与 counter 同坐标对齐，而在 counter 邻域里找最有用处的观测。

### 10.2 Student — Orbit-Conditioned Complement Prediction

```
F̃_t = (1 + γ_o) ⊙ F_t + β_o      # FiLM，只调制 complement 分支，主干分割路径不动
C_S = P(F̃_t)                     # 两三个卷积块
F_S = F_t + C_S      z_S = D(F_S)
```

`e_ASC` / `e_DESC` 两个 embedding → MLP → `(γ_o, β_o)`。语义是**当前缺失的是哪个反向视角**，不是「这是 ASC/DESC」。
无 token、无 experts、无 router、无 dynamic convolution、无独立 spatial gate、无多尺度 predictor。

### 10.3 损失

- `L_seg` 在三类 temporal pair 上算（pre→post / pre→pre / post→post）；
- `L_dist = D(C_S, sg(C_T))`，**只在真实 pre→post 上算**；
- `L_S = L_seg + λ·L_dist`。**一个 λ。**

### 10.4 与旧机制的边界（已划清）

`gain×protect`、`L_pred`（logit KD）、`G_T`、dynamic experts、EMA 归一化、`L_Δ`、P3/P4 递进修正 —— **全部留在旧机制或诊断实验里，不进入新主方法**。
由此形成干净对照：**`R3` = selective prediction KD；`New COCD` = explicit complement distillation。**

推论：本文档 §1–§9 里关于 `w` 分布（v2 活跃 61%）、归一化常数、`s_comp/s_pred` 的讨论**随之作废** —— 不是被解决，而是那些项已不在体系里。

### 10.5 三条仍属「方法级」（不是工程约束）的注记

1. **消融阶梯实际是三级。** 上一版定义的 `N3 = Full COCD（complement-level + decision-level 两项蒸馏）`，在删掉 `L_pred` 后与 `N2` 重合。实际只剩 **`N0` 单轨 / `N1` +Complement Predictor（仅 seg loss）/ `N2` +Complement Distillation（= Full）**；可选补一个很便宜的 `N2 w/o Orbit Embedding`。
2. **「任务相关性是否自动成立」是待观测项，不是待修补项。** 旧 Teacher 的 `r` 同样只由 self/dual 的分割 BCE 驱动，却仍表现为「无变化对上更大」（v1 12.4× / v2 2.0×）。这与「该不该加模块」无关：零参照已被保留，`counter-drop` 诊断的能力还在，**用测量回答即可**。测到的现象不意味着网络里要加一个模块；有时正确处理就是「旧解释不成立，所以不用这个机制」。
3. **单注入点是一个方法级陈述**，不是实现细节：互补只在 FPN 融合后的统一特征上注入一次。论文应写成 "single injection point at the fused feature"，否则会被问为何不做多尺度。（`p2` 是实现细节，可说可不说。）

### 10.6 唯一待定数

`λ`。`L_dist` 是 1/4 分辨率特征空间的距离、`L_seg` 是 BCE，两者尺度不同 —— **只需在开跑前做一次量级测量**（固定初始化下二者的初始比值），据此定一个固定 λ 并冻结。这是一次标定，不是归一化系统。

## 11. λ 与 Teacher audit（2026-09-18 22:14 定案）

### 11.1 λ 的标定规则

在固定的 **train real pre→post 子集**上、不更新参数，测 `L_seg⁰` 与 `L_dist⁰`，然后

```
λ = 0.1 · L_seg⁰ / L_dist⁰          # 使训练起始时 λ·L_dist ≈ 0.1·L_seg
```

λ **永久冻结**，不看 validation、不做 sweep。取 10% 而不是 1:1 的理由：segmentation GT 是真正的任务监督，必须主导；但若只有 ~1%，会重演此前「蒸馏项存在、却没有足够优化权限」的问题。

**两个仍需钉住的点：**

1. **`D` 与聚合方式未指定。** `L_dist = D(C_S, sg(C_T))` 里的 `D` 是 L1 / MSE / SmoothL1 / cosine 尚未定，而 `L_dist⁰` 的尺度**完全由它决定**（学生 near-zero 初始化下 `L_dist⁰ ≈ D(0, C_T)`）。聚合建议用**普通空间均值**——特征匹配不存在类别不平衡，不需要前景/背景平衡聚合（那是分类损失才需要的）。若取 MSE，项会集中在 `|C_T|` 大的区域（v2 实测 `|C_T|` 均值 0.23、max 3.1），L1 更平坦。这是**一个定义选择**，不是归一化系统。
2. **标定必须钉在共享的 scratch 初始化上，只做一次、所有臂共用同一个 λ。** 否则各臂的辅助强度不同，受控比较随之失效。v2 下所有内部臂都是 `init: scratch`，所以标定基准是唯一的。

### 11.2 关于「10%」的口径

`λ` 保证的是**初始**比值 ≈10%，不是全程。`L_seg` 从 0.74（scratch 初始）迅速下降，`L_dist` 随 `C_S` 逼近 `C_T` 也下降，两者速率不同 ⇒ 比值会漂。**建议把若干 epoch 的实测比值作为诊断记录下来**（这正是「实验诊断」该待的地方），**但不因此加归一化**。论文如实写「初始约 10% 辅助强度」。

### 11.3 Teacher audit（训完 Teacher、开训 Student 之前的前置资格检查）

```
correct counter   vs   zero counter   vs   shuffled counter
```

看三件事：① `dual > self` 是否成立；② correct 是否明显优于 zero 与 shuffled；③ `C_T` 在三条件下是否合理变化。

**四点要钉：**

1. **zero counter 是退化情形。** 由恒等式 `C_T(F_c=0) ≡ 0`，它平凡地给出 `C_T = 0`。所以**信息量在 correct vs shuffled**（两者都非零），zero 只是锚点，不要把 zero 的表现当成证据。
2. **shuffled 的定义要与 v1 连续。** v1 用的是「外来地点的**同轨**观测」，测得 AUPRC −0.1137。沿用同一构造，新数才与旧数可比。（ASC↔DESC 互换是另一个检验，若要测应分开报告。）
3. **判定阈值应预先写定，噪声底用 Teacher 自己的训练曲线取。** 用同一读数在相邻评估点之间的最大波动作为噪声底（T2a 曾有 0.01120 的先例），要求 `correct − shuffled` 超过该底。这样不需要新跑实验就能把规则事前钉死。
4. **audit 应同时按 G00/G01/G10/G11 分区报告 `dual − self`。** v1 及其后每一轮的排序都是 **G10 最大**；新 Teacher 若复现同一排序，是「counter 增益落在此该落的位置」的最强证据，成本为零。

### 11.4 定稿的四句话（可直接用于论文）

1. **消融三级**：`N0` 单轨 / `N1` +Complement Predictor（仅 seg loss）/ `N2` Full（= N1 + complement distillation）；另加 `N2 w/o Orbit Embedding`。**无 N3**，不把 `L_pred`、`L_Δ` 搬回来。
2. **互补只注入一次**：*Instead of injecting cross-orbit information at multiple pyramid levels, the complementary representation is introduced once at the fused semantic feature.* 解释句：FPN 已负责多尺度建模，COCD 不再重复做 multi-scale fusion，只负责学习「另一轨额外贡献的互补表示」。
3. **任务相关性的表述**：**不先验宣称**「我们提取出了任务相关互补信息」，而写成「设计了一个由 landslide objective 驱动的 cross-orbit complement representation」，**训完用 Teacher audit 验证它是否真的具有该性质**。若 audit 失败 ⇒ 不继续蒸 Student。
4. **训练目标**：`L_S = L_seg + λ·L_dist(C_S, C_T)`，distillation 只在真实 `pre→post` 上计算。

### 11.5 边界（防止反向长成新机制）

`w` 分布、初始化策略、MPS 算子可用性、断言写法、数值稳定性 —— 一律归入**实现测试清单**（现行位置：`scripts/48` 的断言集、`scripts/47` 的可行性测量），**不得反向长成新的网络机制**。
