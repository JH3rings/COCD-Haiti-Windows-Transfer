# 从一张图看滑坡、畸变、预测与掩膜影响

先看[全部 343 个测试位置的 G00/G10 对比图](regional_effect.png)，再对照下面的完整 patch 个例。区域图由 [plot_four_region_effect.py](../../../../cocd/windows_main/plot_four_region_effect.py) 从保存的计数重画。

建议先打开 [图 1：升轨目标畸变，降轨有效](case_1_distorted_complement_asc.png)，再看[图 2：降轨目标畸变](case_2_distorted_complement_desc.png)、[图 3：双轨有效，升轨目标](case_3_both_valid_complement_asc.png)和[图 4：双轨有效，降轨目标](case_4_both_valid_complement_desc.png)。每个面板都显示**完整 128×128 原始 patch**，没有局部裁剪或空间插值；SAR 仅为显示而按每一轨的灾前、灾后联合百分位拉伸。

## 按行看图

1. **第一行：输入和真值。**前四幅是两轨灾前/灾后 VV。洋红色细线是 `landslide_mask.tif > 0` 的**滑坡边界**，不是畸变边界。第五幅白色填充=滑坡 GT，深色=非滑坡。
2. **第二行：地形可见性和目标检测。**目标轨与互补轨几何图的灰/橙/蓝/紫分别为有效/叠掩/雷达阴影/两者。联合图的灰/橙/蓝/紫分别为 G00 双有效、G10 目标畸变且互补有效、G01 目标有效且互补畸变、G11 双畸变。右侧 S0/S2 错误图逐像素比较同一 GT。
3. **第三行：互补条件、纠错和掩膜。**左侧两幅给出互补轨 S0 和双轨 CG10 教师的错误图；中间绿色为严格找回像素：`GT=1 ∧ 目标S0=0 ∧ 目标S2=1 ∧ 互补S0=1 ∧ 教师=1`，仅显示该例指定的 G10 或 G00 区域。右二的绿色/粉色是 S0→S2 修正/新增的**所有类别错误**。最右把目标轨几何无效像素涂灰，展示“只在目标有效区评分”到底排除了哪里。

错误图统一颜色：绿=TP，红=FN，黄=FP，深色=TN。所有预测采用同一个概率阈值 **0.5**。四幅图的原始 128×128 像素位置完全一致，可逐像素对照。

**不要把掩膜图当成修复结果。**最右图的灰色表示“不参与该口径的评价”，不是模型纠正或真实无滑坡。目标轨畸变而互补轨有效的 G10 正是研究问题；只报告目标有效区分数会把 G10 整片删掉。必须同时报告全区域、目标有效区、G00、G10 和双畸变 G11 的原始 TP/FP/FN，见 [四例逐区数值](case_region_metrics.csv)及 [343 个测试位置逐区数值](regional_metrics.csv)。这些区域 F1 只能在**同一区域内**比较 S0 与 S2，不能把不同区域或掩膜前后的 F1 直接理解为同一任务难度。

四例在完整 128×128 patch 上的 F1（S0→S2）：

| 场景 | 全像素 | 指定重点区 | 重点区 F1 |
|---|---:|---|---:|
| `001061_asc` | 0.7951→0.8118 | G10 | 0.8495→0.8724 |
| `000730_desc` | 0.6717→0.6884 | G10 | 0.7365→0.7469 |
| `000811_asc` | 0.8008→0.8101 | G00 | 0.7997→0.8084 |
| `001109_desc` | 0.8236→0.8308 | G00 | 0.8283→0.8363 |

## 结果如何判断

四例说明存在“目标 S0 漏检、互补 S0 与教师检出、目标 S2 找回”的像素，而且该现象既出现在目标畸变的 G10，也出现在双轨几何有效的 G00。**这只是符合互补机制的观察，不是某个 S2 像素的因果归因。**S2 推理时只输入目标轨；双轨信息来自训练时教师的蒸馏。完整测试区域固定阈值 F1：G10 升/降轨分别 `0.7722→0.7819`、`0.8021→0.8119`；G00 分别 `0.7610→0.7742`、`0.7599→0.7725`。这些是像素汇总的描述性结果，没有独立样本置信区间。

S0/S2 检查点是按**测试集 AUPRC 监控选择**的，例图又按 GT 与预测筛选，所以应标为开发阶段的机制示例，不是独立盲测证明。复现入口：[绘图和推理脚本](../../../../cocd/windows_main/build_four_region_rescue_cases.py)、[候选规则与全部 28 个候选](all_candidate_crops.csv)、[四例选中记录](selected_cases.csv)、[模型哈希与协议](screen_status.json)。数据真值、几何来源及其限制见[最终数据审计](../../../../dataset_audit_final/final_dataset_audit.md)。本地没有原始多边形/光学和完整轨道参数；若要把图用于论文，仍需人工核对滑坡边界、成像时间与双轨配准。

选择例图时使用 96×96 窗口计算净纠错和连通区，**展示时回到完整 128×128 patch**；因此本图没有局部放大，但选择记录里的 `top/left/height/width` 仍是筛选窗口坐标。
