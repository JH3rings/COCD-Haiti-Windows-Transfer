# Qualitative summary

Scenes and crops were selected automatically using fixed test-set masks and errors, then constrained to distinct source scenes. Figure A includes three high TGD recovery scenes and one low-TGD positive reference scene. Figure B uses strict TGD ∧ GT-positive ∧ SO-wrong ∧ S2-correct components. Figure C uses the fixed OmegaTR definition. The figures therefore support local recovery claims without using manually selected screenshots. Error colors expose false negatives rather than relying only on visually favorable masks.

Only SO, S0, S1, S2, and CG10 have reproducible final-protocol predictions in this package. External baselines are intentionally absent. Quantitative scene and crop tables accompany the figures.
