# Haiti 数据集：先看这五张图

这份入口只指向**当前可复核的结果**，不要求先读历史运行目录。

1. [全测试集分区效果图](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/regional_effect.png)：同一 0.5 阈值下，比较目标单轨 S0 与蒸馏后 S2 在 G10（目标畸变、互补有效）和 G00（双轨有效）的 F1。这里是 343 个测试位置的描述性像素汇总，不能当独立盲测。
2. [案例 1：升轨畸变、降轨有效](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/case_1_distorted_complement_asc.png)：优先看这一张，完整 128×128 patch 同时列出双轨 SAR、滑坡 GT、几何掩膜、S0/S2、教师、纠错和 mask 后留下的评价域。
3. [案例 2：降轨畸变、升轨有效](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/case_2_distorted_complement_desc.png)。
4. [案例 3：双轨几何有效，升轨目标](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/case_3_both_valid_complement_asc.png)。
5. [案例 4：双轨几何有效，降轨目标](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/case_4_both_valid_complement_desc.png)。

图上洋红轮廓是**滑坡真值**，不是畸变线；GT 白色填充也是滑坡。目标/互补 `geometry` 面板的灰色为可见，橙色为叠掩，蓝色为雷达阴影，紫色为两者兼有。联合掩膜的橙色 G10 才是“目标轨畸变而互补轨有效”。错误图的绿色/红色/黄色/深色分别为 TP/FN/FP/TN。最右的灰色仅表示**被目标有效区评价口径排除**，并非模型已修好或该处无滑坡。

看“有没有效”时，先固定同一位置、同一 GT、同一阈值，比较目标 S0 和 S2 的红/绿/黄变化；然后查[四例全 patch 各区原始 TP/FP/FN](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/case_region_metrics.csv)和[343 位置全区域 TP/FP/FN](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/regional_metrics.csv)。**目标有效区 mask 会删除 G10，故不能仅凭 mask 后 F1 评价“畸变被救回”。**图只给出与互补视角蒸馏一致的现象，无法归因到单个像素；模型检查点曾受测试集 AUPRC 监控。

需要进一步查数据来源和可靠性时，再读[最终质量审计](final_dataset_audit.md)；人工核查按[盲看指南](03_manual_qc/visual_interpretation_guide.md)做，异常只作为候选，不自动判错。[图的逐格说明与复现](../experiments/GRSL_complete_paper_package/qualitative/four_region_rescue/README.md)记录具体筛选规则与检查点哈希。

本目录其余内容按用途保留：`01_statistics/` 是可追溯统计；`02_tables/` 是逐 patch 和异常表；`03_manual_qc/` 是未填写结论的人工审查材料；`04_anomaly_cases/` 是需复核的可视化候选；`05_existing_results_reused/` 是经筛选保留的历史来源；`99_cleanup_manifest/` 是移动、删除和哈希操作的记录。原始 SAR/GT、划分、检查点和训练结果仍位于其既定项目位置。部分 `04_anomaly_cases/` 根目录图片与类型子目录相同，暂时保留，不能理解为更多独立异常。

其中 60 张根目录异常候选图（合计 73,400,284 字节）已与类型子目录图片逐一做 SHA256 相等核验；[待清理清单](99_cleanup_manifest/verified_duplicate_figures_pending_20260928.csv)给出每张的完整路径、字节数、哈希及保留副本。删除操作未执行，故原始审计材料和既有路径仍完整。
