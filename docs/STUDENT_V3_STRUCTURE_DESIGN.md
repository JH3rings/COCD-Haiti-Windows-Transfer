# Student 网络结构提案 v3：驱动 / 算子 / 递进

状态：**已拍板并实施**（2026-09-16 23:30）。§2.1–2.3 结构获准；A/B/C/D 已废弃删除；本轮采用 **R1 / R2 / R3 三臂**而非两批五臂，理由见 §8。
适用：`Haiti_SAR_GRSL_Audit` 的 Ours 蒸馏管线（`scripts/23_train_ours_v2.py`、`models/landslide_cocd_v2.py`）。

---

## 0. 这份提案在回应什么

现在的蒸馏是在**输出端**给学生加一张权重图（gain / protect / G10）。这只能决定"哪些像素值得学"，决定不了"学什么算子"。

提案把蒸馏从"给答案"改成"给算子"：

> **Teacher 提供的是一个修正算子 Ω —— 由真实反轨训练得到的、把「一条额外证据」转换成「目标轨判别状态改变」的映射。Student 继承这个算子，只学一件事：在没有反轨的情况下，从目标轨自身的状态把「修正驱动」造出来。**

配套两条结构主张：

1. **递进**：P4 先修正；修正后的粗尺度状态进入 P3，P3 在这个**已修正**状态上再修正。
2. **显式 self 参照**：零驱动 → 零修正（`Ω(a, 0) = 0`），所以"反轨带来的收益"可以逐像素度量，Teacher 的 self path 与 dual path 之差有明确含义。

算子继承、递进、self 参照这三条都是**待验证的结构假设**，不是已证明的优势。

## 1. 现状与差距

| 环节 | 现在的做法（v2） | 缺什么 |
|---|---|---|
| 编码 | 共享 ConvNeXt-Tiny；目标轨与反轨各自过一遍 `encode`。每轨输入本身是「同轨 pre/post 叠通道 + orbit」的 5 通道，**同轨时序比较在共享编码器内部完成** | — |
| Teacher 修正 | `a3/a4` 读 `cat(目标轨特征, 反轨特征)`，再减去「counter 置零」的参照 → `r3/r4` | — |
| 解码 | `states()` 三次解码：`z0`（无修正）、`z4`（仅 P4）、`z34`（P4+P3） | P3 的修正头读的是**未修正**的 `p3/p3c`，它不知道 P4 已经改过什么 |
| Student | `q3/q4` 各自 `1×1→3×3→1×1`（末层零初始化），从 `p3/p4` 直接回归一个 residual | 从零学「修正该怎么起作用」；Teacher 已经学过的修正算子被丢掉 |
| 蒸馏 | `selective_kl`：`gain × protect`（±G10）加权的输出 KL | 只能选「哪里学」，不能决定「学什么」 |

结构上最大的浪费是：**Teacher 已经用真实反轨学会了「证据如何改变判别状态」，Student 却只能从零重新学这件事。**

## 2. 提案（对现在的版本做最小改动）

### 2.1 把 Teacher 的修正重解释为「算子」，Student 复制它

Teacher **完全不动**（零改动、零重训）。把已有的 `a3/a4` 看成一个算子：

```
Ω_k(a, c) = a_k(concat(a, c)) − a_k(concat(a, 0))        k ∈ {3, 4}
```

- `a`：目标轨在该尺度的当前状态（128 通道）
- `c`：反轨在该尺度的变化特征（128 通道）
- 性质：**Ω_k(a, 0) = 0**，精确成立（已实测 `max|·| = 0.000e+00`）

Student 新增一个 Driver 模块 `Q_k`（`3×3, 128→32→128`，末层零初始化），从目标轨**自身状态**预测「反轨变化特征的替代品」，再交给**复制过来的** Ω：

```
ĉ_k = Q_k(a_k)            # 零初始化 → 初始 ĉ = 0
r_k = Ω_k(a_k, ĉ_k)       # 用 Teacher 的算子，不是新学一个 residual 头
```

分工因此变得清楚：

- **Ω**：「一条额外证据应该怎样改变当前判别状态」 —— Teacher 在真实双轨数据上学到，Student 直接继承。
- **Q_k**：「没有反轨时，根据目标轨当前状态应该造出什么驱动」 —— Student **唯一**需要从零学的东西。

### 2.2 修正变成递进的

P3 的修正作用于 **P4 修正之后**的 P3 状态：

```
p4 → r4 = Ω4(p4, ĉ4)  → h4 = p4 + r4
a3 = l3(C3) + Up(h4)                      # P3 状态已经吸收 P4 修正
r3 = Ω3(a3, ĉ3)       → h3 = a3 + r3
z34 = decode(h3, h4)
```

与现在唯一的结构差别：`r3` 的输入状态由「未修正的 p3」换成「已修正的 a3」。P3 学的不再是"再补一块特征"，而是"在粗尺度已经改过之后，还该怎么调"。

### 2.3 完整 Student 前向（新）

```
输入：目标轨 5 通道（pre VV/VH, post VV/VH, orbit）——不含反轨、不含几何
ft = encode(target)
c2, p3, p4 = pyramid(ft)

ĉ4 = Q4(p4);   h4 = p4 + Ω4(p4, ĉ4)
a3 = l3(ft[1]) + Up(h4)
ĉ3 = Q3(a3);   h3 = a3 + Ω3(a3, ĉ3)

z4  = decode(c2, a3, h4)     # 训练期读出的中间态（P4-only）
z34 = decode(c2, h3, h4)     # 部署输出（P4+P3）
```

### 2.4 初始化与不变量（已实测）

| 不变量 | 实测结果 |
|---|---|
| `Ω_k(a, 0) = 0`（零驱动 → 零修正） | `max abs = 0.000e+00` |
| Student 初始输出 ≡ Teacher self path | `max abs diff = 0.000e+00` |
| 递进但零驱动时 `h4 == p4` | `max abs diff = 0.000e+00` |

Student 初始化：backbone + decoder + Ω3/Ω4 全部复制自 Teacher，`Q3/Q4` 零初始化。
训练的起点与现在完全一致（起点是"已知不错的单轨网络"），但 Student **一开始就已经拥有把驱动变成状态改变的算子**——这正是继承与从零学的区别。

## 3. 目标函数：不动

```
L = 0.5·(L_seg(z4) + L_seg(z34)) + 0.5·(KD4 + KD34)
```

KD 仍是 `selective_kl`（`gain × protect` 加权、T=1 的 Bernoulli KL）。**不加**特征 MSE、不加 relational KD、不加梯度匹配。

论文里贡献落在这三件事上：**有显式 self 参照的 Teacher + 可继承的修正算子 + 递进的逐层修正**；监督选择（gain/protect/G10）是配套。不是"给普通 KD 乘一张权重图"，也不是"首次提出残差块"。

## 4. 消融：用 R0–R4 替代 A/B/C/D

五个臂的网络结构、Teacher、数据、epoch、优化器、KD 配置（`gain × protect`）**全部相同**，唯一变量是结构。

| 臂 | ĉ 的来源 | 修正算子 | 递进 | 输出 KD |
|---|---|---|---|---|
| **R0** | 无 | 无（恒等） | — | 无 |
| **R1** | 自己的 `q_k`（从零学 residual） | 无 | 否 | 有 |
| **R2** | `Q_k(a_k)` | **继承 Teacher Ω** | 否 | 有 |
| **R3** | `Q_k(a_k)` | **继承 Teacher Ω** | **是** | 有 |
| **R4** | `Q_k(a_k)` | 继承 Teacher Ω | 是 | 无 |

每一对只差一个因素：

- **R1 − R0**：修正能力 + 蒸馏整体有没有用（= 现在的设计）
- **R2 − R1**：**继承算子**的贡献 ← 提案的核心主张
- **R3 − R2**：**递进**的贡献
- **R3 − R4**：输出蒸馏在这个结构上还剩多少增量（结构 vs 监督的分离）

**分批执行**（batch 8，约 2.6 h/臂）：

- 第一批 **R0 / R1 / R3**，约 7.8 h。直接回答"新结构是否优于现状、现状是否优于地板"。**若 R3 ≤ R1，第二批不必跑。**
- 第二批（按需）**R2 / R4**，约 5.2 h，用于归因。

## 5. 明确不做的事

1. **不改编码器输入，不做显式 change feature**（`C_o = Φ(E_pre, E_post, E_post − E_pre)`）。
   现在每轨的 5 通道输入已经是「同轨 pre/post 叠通道 + orbit 标识」，同轨时序比较在共享编码器内部完成。把 pre/post 拆开重做会破坏 S0 检查点的加载路径，并让已冻结的 Teacher 作废，代价远大于收益。
2. **不重训 Teacher。** 提案对 Teacher 零改动，现有验证结果（0.8963）继续有效。
3. **不新增特征蒸馏 / relational KD / 梯度匹配。** 这些是 DIS2 已经做过的东西，加进来只会削弱差异。
4. **不要求 `ĉ_k = c_k` 或 `r_k = r_k^T` 逐通道成立。** 单轨在物理上无法复原反轨信息，降维解决不了信息缺失。要求的是：Student 在自身可得信息的约束下，产生能通过 Ω 改善判别的驱动。

## 6. 与 DIS2 的差别（按 vendored 源码核对）

对 `third_party/landslide_baselines/dis2/` 的快照逐项核对，DIS2 已经包含：Distinct/Supplement 双分支、正交解耦损失（`divergence`）、多尺度 L2 归一化特征 MSE、T=2 的 logit KL。所以差异不能建立在"我们也有补偿分支 + 多尺度蒸馏"上。

| 问题 | DIS2 机制 | 提案机制 |
|---|---|---|
| 补偿围绕什么组织 | 缺失模态下的表征补偿与融合 | **围绕目标轨已有的时序判别状态做修正** |
| Student 额外学什么 | 用可用输入学补偿表征 | **继承修正算子 Ω，只学驱动 Q** |
| 修正如何影响结果 | 多尺度融合后分割 | **粗尺度修正进入细尺度解码，形成递进判别** |
| 哪些 Teacher 信息值得学 | 完整观测特征与输出提供监督 | **相对 self 的实际收益 + 几何互补** |

---

## 7. 诚实边界

- 若 **R2 ≈ R1**（继承算子没作用）：说明 Ω 在单轨条件下无法被有效驱动，结构部分放弃，**贡献收敛到监督选择**。
- 若 **R3 ≈ R2**（递进没作用）：递进作为负结果如实报告，主方法退回 R2。
- 若 **R1 ≈ R0**：蒸馏空间本就不存在，后面全部空转。
- 以上任何一种结果都如实写，不把结构包装成关键创新。
