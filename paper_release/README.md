# Frozen GRSL evidence — 30 September 2026

The final method transfers counter-guided **target-evidence selection and aggregation** to a single-orbit Student. Counter features determine only the Teacher policy. Both evidence-distillation retrievals use the same detached Student target memory. Geometry is used only for post-hoc evaluation. See [final_method.json](final_method.json) for exact code, checkpoint hashes, KD definitions and gradient paths, and [protocol.json](protocol.json) for the dataset/split/normalization contract.

Use [main_comparison.csv](results/main_comparison.csv) for the five exact-protocol results. External distillation methods are documented Haiti adaptations, not numerical reproductions of the published benchmarks. SAR U-Net++ and other single-orbit seats have a different configured epoch ceiling and are separated in [protocol_different_comparison.csv](results/protocol_different_comparison.csv). Their runs stopped below both ceilings; this does not erase the configuration difference. DIS2's manuscript row is [historical reported-only](results/historical_reported_only.csv), without matching checkpoint/probability lineage or current regional metrics. [baseline_audit.csv](baseline_audit.csv) records availability and implementation limits.

Numbers in this release follow retained-checkpoint/prediction recomputation. Small disagreements with old summaries are explicit in [result_source_conflicts.csv](result_source_conflicts.csv); old summaries and the manuscript are unchanged. [claim_audit.csv](claim_audit.csv) identifies nine manuscript mismatches, including some two-decimal table cells and the description of Policy KD. Read these before rewriting. CSV metrics are fractions, not percentages. Empty historical values mean unavailable, not zero. All current comparisons are single-seed; no variance or significance is inferred.

[mechanism_guidance.csv](results/mechanism_guidance.csv) separates independently trained self guidance from frozen interventions. Correct pairing helps; arbitrary offsets hurt. Fixed-center Student sampling is nearly as good as learned offsets. The three learned candidates coincide in both frozen checkpoints. Large displacement necessity and causal scale-weight importance are **not established**. [distillation_ablation.csv](results/distillation_ablation.csv) contains matched objective controls: Policy alone improves the segmentation control, Evidence alone does not, and their combination is best in this one run. The separately retrained segmentation control must not replace the primary baseline.

[Figure audit](figures/figure_audit.csv) retains the original task scenario, the editable current architecture and existing qualitative candidates. Intended paper structure: task Figure 1, architecture Figure 2, one compact qualitative Figure 3, exact-protocol Table I, and Table II with guidance/objective panels. Full-pixel and search assets are optional candidates, not instructions to add more figures. Candidate cases and geometry maps still require human scientific review.

[baseline_references.bib](baseline_references.bib) contains external-method references; [reference_audit.csv](reference_audit.csv) records primary metadata checks. Multi-to-Uni is cited as available online in 2026, with its assigned 2027 volume noted. All 23 original references remain in [context_references.bib](context_references.bib). Existing paper stays five pages; no manuscript rewrite was performed.

Limits: 1,370/0/343 spatial locations; checkpoint selection monitors **test** AUPRC; these are test-monitored development results, not independent validation. Models train on all labelled pixels. Existing geometry maps are not independently validated distortion ground truth. OGP-Net did not complete its benchmark; local DIS2 port results cannot replace the historical DIS2 row. Further historical table entries have unresolved lineage and are ineligible unless separately audited.
